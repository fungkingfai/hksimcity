# 《維港之城》香港在地化內容包（HK_LOCALIZATION.md）

> 文件版本：1.0（2026-10-21）｜撰寫：game-designer
> 專案：`hk-city/`（《維港之城》）
> 用途：給 **world-dev**（地圖地名／街道）、**buildings-dev**（霓虹招牌／店名／室內招牌）、**ui-dev**（文案／用語／節慶）直接取用的內容包。
> 依據：`src/core/config.ts` 的 `MAP_LABELS`／`STREET_NAMES`／`NEON_SIGNS`／`SURNAMES`／`GIVEN_NAMES`、`docs/GAME_DESIGN_HK.md`、`docs/UI_SPEC_HK.md`、`docs/RESEARCH_HK.md`。
> 標記：**✅ 可直接用**｜**🔁 可循環組合**｜**🎨 需美術配合**｜**⚠️ 用前確認**。
>
> **命名原則**
> 1. **地名、街道、交通站名**可用真實香港公共地名（方便玩家辨認）；**店舖、屋苑、商廈、商場名一律虛構**，避免與現實商標／品牌混淆。
> 2. 全部**繁體中文、香港用語**；不使用簡體、不用「小區／公交／出租車」等內地用語。
> 3. 名稱長度：建築招牌 ≤ 8 字；霓虹直式招牌 ≤ 4 字；街道名 ≤ 8 字；新聞標題 ≤ 16 字（UI 免換行）。
> 4. 所有名單由 seed 決定性抽取（同一存檔不變），不要每次渲染重抽。

## 4. 事件／新聞文案

### 4.1 語氣規則

- **報章風**：主標 ≤ 16 字、口語但克制；副題補充數字與影響。例：「八號風球懸掛　全港停工停課」。
- **政府新聞稿風**（教學／公告）：正式、簡短，用「政府呼籲」「市民請注意」。

### 7.2 分配規則（deterministic）

- 世界生成：用 `seed` 決定街道名與地名牌（同一格不重複）；每條主幹道最多 1 個路牌。
- 建築：用 `building.id` 或 `seed + tileIndex` 抽店名／屋邨名；同類建築避免連續 3 棟同名。
- 霓虹招牌：唐樓／舊區才有；用 `NEON_COLORS` 抽色；同一街區招牌不超過 8 個，避免視覺爆炸。
- UI：新聞／事件文案按 `id` 抽，不要每次 toast 都重抽；同類事件 24 遊戲小時內不重複。

### 7.3 不要做

- 不要在 UI 寫死店名／屋邨名（應由 seed 抽）。
- 不要用真實品牌／商標／政治人物。
- 不要把「18 區」當成 18 個可建區（遊戲只有 7 個玩法區域；18 區只作地名標籤）。
- 不要為節慶新增 GameState 欄位（用現有 `finance.lastFestivalDay`／log／幸福加成）。
