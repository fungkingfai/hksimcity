## 1. 設計方向：霓虹港風

### 1.1 一句話

> **深夜的維港、霓虹招牌的粉紅與青綠、港鐵色帶、紅白藍帆布、雙層巴士的黃——但介面要清楚過霓虹，任何時候玩家都知道下一步做什麼。**

### 1.2 三大視覺元素

1. **深藍夜色底＋霓虹光**：面板是半透明深藍（`#101b2e` 90%），邊框用霓虹粉／青綠 1px；重要數字與按鈕發光，但**文字對比 ≥ 4.5:1**。
2. **港鐵色帶**：交通相關 UI 用港鐵紅（#b02a2a）、巴士黃（#d9b23f）、電車綠（#2f8f5f）、渡輪青綠（#2f7f6a）；分類 tab 用 `CATEGORY_INFO.color`。
3. **香港符號**：霓虹招牌字（`NEON_SIGNS`）、街道名（`STREET_NAMES`）、紅白藍膠袋紋、唐樓鐵閘、天星小輪、叮叮剪影；**全部以 CSS/SVG 自繪，不載入外部圖片或字型**。

### 1.3 禁忌

- 不要用「大陸 App 風」：大紅漸變、金色邊框、圓角 20px、卡通插畫、簡體字。
- 不要用「西方賽博朋克」：過量紫藍漸變、故障藝術、難以閱讀的字體。
- 不要讓霓虹蓋過資訊：發光只用於 hover／選中／警告，不用於內文。

## 3. 字體與排版

| 層級 | 大小／行高 | 字重 | 用途 |
|---|---|---|---|
| H1 城市名 | 20px／1.2 | 700 | 頂欄品牌 |
| H2 面板標題 | 16px／1.3 | 700 | 財政／交通／存檔 |
| H3 卡片標題 | 14px／1.3 | 600 | 建築卡、站點卡 |
| 內文 | 13px／1.5 | 400 | 描述、表格 |
| 數字（金錢／人口） | 15–18px／1.2 | 700，`font-variant-numeric: tabular-nums` | 頂欄、報表 |
| 說明／次要 | 11–12px／1.4 | 400，`--hk-text-dim` | tooltip、註腳 |
| 按鈕 | 13px／1 | 600 | 主要 CTA |

- 字體：`--hk-font`；**不載入外部字型**，用系統 Noto Sans HK／PingFang HK。
- 中英混排：中文與英文之間留半形空格（「港鐵 MTR」）；數字與單位之間不留空格（`$18,000`）。
- 金錢格式：`formatMoney`（`$1,234,567`）用於詳細數字；`formatMoneyShort`（`$123.5萬`／`$1.23億`）用於頂欄與卡片。
- 日期格式：`第2年 8月 14日 · 星期五 · 14:30`（`clock.weekday` 0=星期日）。

## 4. 圖示與材質

| 元素 | 規格 |
|---|---|
| 建築圖示 | 每個 key 一個 24×24 SVG（線稿＋分類色）；未解鎖加鎖頭 |
| 交通工具 | 雙層巴士（黃／紅）、小巴（綠）、的士（紅）、叮叮（綠）、港鐵（紅）、天星小輪（青綠）、貨車（白／藍） |
| 霓虹招牌 | SVG 文字牌（`NEON_SIGNS` 20 個字），夜間發光，hover 時亮度 +20% |
| 材質 | CSS `repeating-linear-gradient` 做紅白藍膠袋紋（用於 modal 頂部 6px 裝飾條）、掃描線（用於 loading） |
| 邊框 | 1px `rgba(36,224,255,.18)`；選中 2px `--hk-pink`＋外發光 |
| 圓角 | 6px（面板）／3px（小卡）；不用大圓角 |
| 陰影 | `--hk-shadow`；霓虹只用在強調元素 |
| 動畫 | 面板淡入 160ms、toast 200ms、按鈕 hover 上浮 1px；**克制**，不做大幅位移 |
| 無外部資源 | 不使用外部圖片／字型／icon 套件；全部 SVG／CSS |

### 5.1 Minimap（600×600 真實地形導覽）

| 項目 | 規格 |
|---|---|
| 位置／尺寸 | 桌面：畫布**右下角**浮動面板；地圖 canvas **600×600** 內部解析度（真實地形＋水塘／土地利用；數據來源見 `REAL_GEO_DATA.md`）；250ms 節流、地形快取 |
| 顯示內容 | **真實地形**（水域／山／林地／市區／填海底色）、道路（淺灰）、四色分區（半透明）、建築點（auto 用分區色、ploppable 用分類色＋白點、**existing 用淡白圈**）、城市中心 spawn（粉紅點）、**深圳河／口岸標記**、鏡頭視野框（青色）；600 地圖下 minimap 是主要 overview |
| 更新頻率 | 地形底色 offscreen 快取（只在 seed／尺寸變更重建）；每 **250ms** 或 `ui.revision` 變更才重畫；拖曳 focus 節流 80ms |
| 點擊／拖曳 | 換算格座標 → `actions.focusTile(tx, ty)` |
| 按鈕 | 「全圖」`fitMap()`（**O**）、「市中心」`focusTile(spawn)`（**P**）、「分區」`toggleZones()`（**L**） |
| 摺疊 | 標題列 chevron；收起只留標題／比例；室內模式與開局畫面自動隱藏 |
| 比例字 | 「600×600」，title「360,000 格」 |
| 手機 | 132px 小地圖，**預設收起**；展開後可點擊跳轉 |

### 5.2 相機 zoom out 範圍（600 地圖，MAP_SCALE=6.25）

| 項目 | 值 |
|---|---|
| 最近距離 | 16 |
| 最遠距離 | `260 × MAP_SCALE = 1,625`（MAP_SCALE=6.25） |
| far plane | `600 × MAP_SCALE = 3,750` |
| `fitMap()`（O） | 目標置中、距離 ≈1,495、pitch 1.12–1.32、yaw −45°；拉遠後可再滾輪放大 |
| `focusTile()` | 距離夾到 ≤90、pitch ≥0.78（minimap 點擊／P） |
| 手機初始 | 距離 110、俯角 0.9、pixelRatio ≤1.75 |

> 大地圖下相機必須保留「遠景 overview」與「貼地建城」兩種尺度；`O` 一鍵拉遠、`P` 一鍵回市中心是主要導航。

## 16. 手機版介面（≤ 768px 自動切換）

**偵測**：`pointer: coarse`／`maxTouchPoints > 0`／行動 UA／iPadOS → 手機版；可用 `?ui=mobile`／`?ui=desktop` 強制。

**佈局**

- 精簡頂欄（48px）：城名、日期、天氣 emoji＋溫度、警告圖示、庫房、人口、暫停／倍速；其餘收進「選單」。
- 底部導覽列 5 項：**建造／城事／財政／交通／選單**；支援 iPhone Home Indicator 安全區（`env(safe-area-inset-bottom)`）。
- 「建造」「城事」用**底部 sheet**（max-height 70dvh，背景遮罩，✕／點遮罩收起）；建造 sheet 以「區域 4 刷子」為首，下面才是工具與 13 張手動置建築卡；需求條固定在 sheet 頂部（4 條橫向）。
- **minimap 132px 預設收起**，可展開；不遮擋底部導覽；展開時可點擊跳轉。
- 財政／交通／存檔／說明用全寬 modal；表格可橫向滾動。
- 室內模式隱藏底部導覽；室內資訊卡限高 48dvh，可滾動。

**觸控**

- 單指點擊：建造／選取；單指拖曳：平移；雙指捏合：縮放；雙指旋轉：旋轉（沿用舊版手勢）。
- 建造工具提示顯示於底部導覽上方，可一鍵取消。
- 所有可點元素 ≥ 44×44px；滑桿 thumb ≥ 24px。

**效能**

- `pixelRatio` 上限 1.75；陰影貼圖 1024；**初始鏡頭距離 110、俯角 0.9**（600 地圖）；市民／車輛／真實樓群 LOD；minimap 收起時不重畫。

**驗收**：iPhone 13 模擬（Playwright）——自動偵測、頂欄、建造 sheet、工具、觸控放置、城事面板、進入／離開室內、單指平移、雙指縮放、財政、**minimap 摺疊／展開／點擊跳轉**、桌面回歸。

## 19. 無障礙與效能

- 對比度：正文 ≥ 4.5:1；大數字 ≥ 3:1；霓虹色只用於裝飾／強調。
- 焦點可見：`outline: 2px solid var(--hk-cyan)`；Tab 順序合理；Esc 關閉 modal。
- `aria-label`：所有圖示按鈕；滑桿 `role="slider"`＋`aria-valuenow`。
- `update(state)` 不得每幀重建 DOM：頂欄只更新變動文字；左右面板以 `ui.revision`／`selectedId`／`tool`／`buildCategory` diff；modal 以開啟狀態＋revision 重建。
- 事件委派（root 上 `data-*`）；市民／車輛用 InstancedMesh；UI 只顯示名單前 8–12 人。
